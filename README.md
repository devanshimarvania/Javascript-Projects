⏳ Countdown & Motivation App
  - An interactive JavaScript-based web application that features a real-time countdown timer, an automatic motivational quotes slider, and a delayed popup for a welcome message. The project uses JavaScript (ES6), DOM manipulation, setInterval, setTimeout, and clearInterval to create a smooth user experience.

✨ Features
- Countdown Timer
  - Displays days, hours, minutes, and seconds to a target event.
  - Start and Pause functionality using setInterval and clearInterval.
  - Displays a “⏰ Time’s Up!” message when the countdown reaches zero.

- Motivational Quotes Slider
  - Stores motivational quotes in an array.
  - Automatically changes every 3 seconds.
  - Includes Next and Previous navigation buttons for manual control.

- Popup Message
  - A welcome modal appears 5 seconds after page load using setTimeout.

🛠️ Tech Stack
  - HTML5 – Page structure
  - CSS3 – Styling with gradients, glassmorphism, and responsive design
  - JavaScript (ES6) – Logic for countdown, quotes slider, and popup

📸 Example Output
  - Countdown: 10d : 5h : 20m : 45s
  - Quote: “Dreams don’t work unless you do.”
  - Popup: “🚀 Welcome to Countdown & Motivation App! Stay inspired until your big day!"
