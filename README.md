🚀 Smart Task & Habit Tracker
  - A simple Task & Habit Tracking Web App built with HTML, CSS, JavaScript, and Bootstrap.
  - It helps you add, manage, search, filter, and track tasks with a clean dashboard.

✨ Features
  - ➕ Add new tasks with title, description, category, date & status
  - 📋 View all tasks in card format with category & status tags  
  - 🔍 Search & filter tasks by keyword or status (Pending / Completed / Overdue)  
  - ✅ Mark tasks as completed or ❌ delete tasks  
  - 📊 Dashboard summary with total, completed, pending, overdue counts  
  - 📈 Progress bar showing completion percentage  
  - 🎨 Responsive UI with Bootstrap & gradient background

🛠️ Tech Stack
  - HTML5 – structure
  - CSS3 + Bootstrap 5 – styling & responsive design
  - JavaScript (ES6) – dynamic functionality & task management

📂 Project Structure
- 📁 Task-Tracker
 - ├── index.html      # Main UI
 - ├── tracker.js      # Task logic (Add, Delete, Filter, Dashboard)
 - └── README.md       # Project Documentation
