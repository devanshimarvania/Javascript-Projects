🌍 Smart Travel Planner

A JavaScript-based console + web application that helps users plan their travel by taking inputs like destinations, budget, and number of days. It provides useful trip suggestions such as trip type, duration, and hotel recommendations.

✨ Features

- 🏙️ Enter 3–5 travel destinations (stored in an array).
- 💰 Budget check with trip suggestions:
    - < ₹10,000 → Short Domestic Trip
    - ₹10,000 – ₹50,000 → Long Domestic Trip
    - > ₹50,000 → International Trip

- 📅 Number of days calculator:
    - < 3 days → Weekend Getaway
    - 3–7 days → Perfect Holiday Trip
    - > 7 days → Extended Vacation

- 🏨 Hotel recommendation function (based on budget/day):
    - Budget Hotels
    - Mid-range Hotels
    - Luxury Hotels

- ✅ Final Travel Summary displayed in console log and browser (document.write).

🛠️ Technologies Used
  - JavaScript (ES6 features: let, const, arrow functions, template literals)
  - HTML (for running the script in browser)
  - Conditionals, Loops, Functions, Arrays
