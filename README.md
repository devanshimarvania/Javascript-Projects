☕ Café Management System (JavaScript)

This is a menu-driven Café Management System built using JavaScript. The project simulates a small café where customers can place orders, view bills, apply discounts, and check café reports.

🔹 Features
- 📋 Menu System – Order Coffee, Tea, Sandwich, or Pastry.
- 🧾 Billing System – Generates bill with GST (5%) and final total.
- 🏷️ Discounts – Automatically applies 10% or 20% discount based on the total purchase.
- 🔐 Password Management – Allows café password change with validation.
- 📊 Café Report – Displays total items sold, highest/lowest price items, and average price.
- ⚠️ Error Handling – Handles invalid inputs and cases where no items are sold.
- 💻 Output Display – Shows results in both console.log() and browser using document.write().
- 🎯 Purpose

This project demonstrates the use of loops, conditional statements, string formatting, user input handling, and basic calculations in JavaScript. It’s a beginner-friendly project that mimics real-world café operations.
