📸 Smart Image Slider

📝 Overview
  - A simple JavaScript Image Slider with Bootstrap 5, allowing users to browse images, view captions, and add their own images dynamically.

✨ Features

  - 🎞️ Prev/Next navigation
  - 📝 Captions + slide counter
  - ➕ Add custom images (URL + caption)
  - 📱 Responsive design
  - 🚫 Alerts on first/last slide

⚙️ Tech Stack

  - HTML5, CSS3 / Bootstrap 5
  - JavaScript (ES6) – Arrays, Objects, DOM Manipulation

📚 Concepts

  - Arrays & Objects for image storage
  - Functions for navigation
  - DOM updates for captions & counter
