This project is a menu-driven JavaScript program that provides 4 main features:
1. Fitness Suggestion System 🏋️‍♂️
2. Monthly Budget Planner 💰
3. Mobile Data Usage Alert System 📶
4. Change Password Logic 🔐

1. Fitness Suggestion System 🏋️‍♀️
  - Takes Age and Weight as input.
  - Compares weight with recommended range for the age group.
  - Suggests if you are Underweight, Overweight, or Fit.

4. Change Password Logic 🔐
  - Validates old password.
  - Ensures new password ≠ old password.
  - Confirms new password = confirm password.
  - Updates password successfully if all conditions are met.

5. Invalid Choice
  - If the user enters a number other than 1, 2, 3, or 4 in the menu,
    the program shows an error message.
  - This ensures the user selects only from the given valid options.
