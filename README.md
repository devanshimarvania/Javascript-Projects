## 🍴 Foodies Hub – Food Ordering & Cart Management System

### 📌 Description

This project is a simple **Food Menu Management and Cart System** built using **HTML, CSS (Bootstrap), and JavaScript**.
It allows users/admins to manage food items (add, view, edit, delete) and customers to add items to a shopping cart.
All data is stored in **LocalStorage**, so the app works without a backend or database.

### 🚀 Features

* **Menu Management**

  * Add new food items with ID, name, category, price, size, stock, ingredients, and image.
  * Display menu items in a dynamic table.
  * Edit and delete items.
  * Prevents duplicate IDs (admin must assign unique IDs).

* **Cart System**

  * Add items to cart from the menu.
  * Increase/decrease item quantity.
  * Prevents exceeding stock quantity.
  * Remove items or clear the entire cart.
  * Shows total price dynamically.

* **LocalStorage Support**

  * Saves menu and cart data in browser local storage.
  * Data persists even after refreshing or closing the browser.

### 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Logic:** Vanilla JavaScript (ES6)
* **Storage:** Browser LocalStorage

### 📷 Example Use Case

* **Admin:** Adds food items with unique IDs (like Pizza, Burger, Drinks).
* **Customer:** Browses menu → Adds items to cart → Adjusts quantity → Proceeds with total price view.
